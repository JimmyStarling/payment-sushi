# payment-sushi-laravel
Microsserviço de pagamentos desenvolvido em Laravel que integra com gateways de pagamento para processar pedidos em um sistema de delivery de sushi. A arquitetura segue os princípios da arquitetura hexagonal (ports &amp; adapters), promovendo separação clara entre domínio, aplicação e infraestrutura. Reformulação do repositório "umsushiapp-squad4".
